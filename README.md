# FastAPI Fundamentals

A beginner-friendly FastAPI project created to practice the basics of building APIs with Python.

## Features

- FastAPI project setup
- GET endpoints
- Path parameters
- Query parameters
- POST requests
- PUT requests
- DELETE requests
- Swagger API documentation

## Endpoints

- `GET /`
- `GET /health`
- `GET /users/{user_id}`
- `GET /search?q=fastapi`
- `POST /users`
- `PUT /users/{user_id}`
- `DELETE /users/{user_id}`

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic
